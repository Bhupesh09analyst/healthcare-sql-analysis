Project Overview

This project focuses on analyzing healthcare data to derive insights related to revenue performance, growth trends, hospital inflow, doctor performance, patient demographics, and high-cost medical conditions.
The analysis was performed using SQL for data transformation and analysis, and Power BI for visualization and dashboard creation.

The goal of the project is to demonstrate an end-to-end analytics workflow—from querying structured data to presenting actionable business insights through interactive dashboards.

 Tools & Technologies

SQL – Data extraction, aggregation, ranking, and trend analysis

Power BI – Data modeling, Power Query, KPI cards, dashboards, and slicers

Excel / CSV – Intermediate data storage and validation

 Dataset Description

The dataset contains healthcare-related information such as:

Billing and revenue details

Hospital-wise patient inflow

Doctor-wise revenue performance

Patient demographics (gender, admission type)

Medical conditions with high billing amounts

(Note: The dataset used is for analytical and learning purposes.)

 Key Analysis Performed (SQL)

Revenue aggregation and trend analysis

Month-on-Month (MoM) revenue growth analysis

Hospital-wise patient inflow analysis

Doctor-wise revenue performance and ranking

Identification of high-revenue medical conditions

Patient demographic distribution analysis

Advanced SQL concepts used:

JOINs

Subqueries

Common Table Expressions (CTEs)

Window functions (RANK, DENSE_RANK)

Aggregate and date functions
